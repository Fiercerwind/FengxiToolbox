风兮文件批量处理工具箱 3.0
==========================

简介
----
风兮文件批量处理工具箱是一款面向日常办公与资料整理场景的本地批处理工具，提供水印、格式转换、音视频处理、PDF 处理、图片处理、压缩、属性修改、文件重命名等常用功能。

当前版本为 3.0，对应 Git 标签版本为 `v3.0.0`。

软件默认以“批量处理”方式工作：
- 选择一个文件夹作为输入目录
- 按当前页面配置处理该目录中的文件
- 结果输出到原目录下的处理结果文件夹

本工具不会主动上传文件，绝大多数功能均在本地完成。

运行方式
--------
1. 运行打包版：双击 `fx_toolbox.exe`
2. 运行源码版：在项目目录执行 `python Fengxi_Toolbox.py`

源码运行常见依赖：
- `customtkinter`
- `pypdf`
- `pdf2docx`

- `rapidocr`
- `onnxruntime`

GitHub 同步与发布
-----------------
项目现已支持将本地代码定期同步到 GitHub，方便回退与发布。

1. 手动同步到 GitHub
- 执行 `powershell -ExecutionPolicy Bypass -File tools\fx_git_sync.ps1`
- 脚本会自动提交当前未忽略改动并推送到当前分支

2. 注册自动同步任务
- 推荐执行：
  `powershell -ExecutionPolicy Bypass -File tools\register_github_sync_task.ps1 -DailyAt 21:30`
- 这样会在每天 21:30 自动同步一次

3. 删除自动同步任务
- 执行 `powershell -ExecutionPolicy Bypass -File tools\unregister_github_sync_task.ps1`

4. 版本发布
- 当前正式版本：`v3.0.0`
- 创建发布标签：
  `powershell -ExecutionPolicy Bypass -File tools\fx_release_version.ps1 -Version 3.0.0`
- 推送标签后，GitHub 会自动构建并发布对应版本

界面说明
--------
左侧为功能导航区：
- 批量水印
- 去除水印
- 格式转换
- 音频工具
- 批量压缩
- PDF 工具
- 图片工厂

顶部为输入目录区：

输出规则
--------
除少数明确为“覆盖式”或“删除原文件”的操作外，工具默认会将结果输出到输入目录下的新文件或结果目录中。

功能总览
--------
1. 批量水印
- 支持对 PDF、Word 等文档添加文字水印
- 可设置水印文本、字体、字号、透明度、旋转角度
- 支持每页生成或仅第一页生成
- 可选兼容模式
- 可选处理后删除源文件
- 保留原有水印逻辑

2. 去除水印
- 用于处理部分带固定水印的文档
- 不同文件类型会按对应逻辑尝试处理
- 某些复杂文档可能无法完美去除，建议先备份原文件

3. 格式转换
- Word 转 PDF
- PDF 转 Word
- PPT 转 PDF
- 支持处理完成后自动打开结果
- 可选处理完成后删除原文件

4. 音频工具
- 视频提取音频
- 音频格式互转
- 常见输出格式包括 `mp3`、`wav`、`flac`、`m4a`、`aac`、`ogg`

5. 批量压缩
- 支持压缩文件夹内容
- 适合整理归档与批量打包

6. PDF 工具
- PDF 加密
- PDF 拆分
- 多图合并 PDF
- OCR 搜索版 PDF

7. 图片工厂
- 图片格式转换
- 图片压缩
- 适合统一图片格式与减小体积

8. 属性隐私
- 修改作者/创建者信息
- 修改文件时间
- 适用于 Office 文档、PDF 及通用文件时间字段处理

9. 文件管家
- 批量重命名
- 添加前缀/后缀
- 查找替换
- 截取头尾字符

常见问题
--------
1. 为什么有些 Word/PPT 功能不能用？
- 这类功能依赖本机安装的 Microsoft Office 与 COM 组件
- 如果系统没有可用的 Office 环境，相关功能可能失败

2. 为什么视频/音频转换失败？
- 请确认输入文件本身可播放
- 请避免文件路径过长或包含异常字符
- 当前版本音频转换优先使用 ffmpeg 后端

3. 为什么字体列表里没有我想要的字体？
- 将 `.ttf` 字体文件放入 `fonts` 目录
- 或放在程序同级目录
- 重启软件后再试

4. 为什么杀毒软件会拦截？
- Python 打包程序有时会被安全软件误报
- 如确认来源可信，可将程序目录加入白名单

5. 为什么我点了“停止”还会继续处理一个文件？
- “停止”通常会阻止后续文件继续进入处理队列
- 正在处理中的那个文件可能会先执行完

注意事项
--------
- 批量操作前建议先备份原文件
- 去水印、重命名、覆盖式处理前尤其建议备份
- 含密码、损坏、受保护或结构异常的文档可能处理失败
- Office 相关功能受本机环境影响较大
